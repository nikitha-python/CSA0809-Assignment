CSA08 Assignment 1 - Python execution files

FILES
- milkrate.py: reusable payment calculator module, validation and self-tests.
- run_all_tasks.py: runs demonstrations for the executable parts of Tasks 2-12.

HOW TO RUN
1. Install Python 3.9 or newer.
2. Keep milkrate.py and run_all_tasks.py in the same folder.
3. Open Terminal / Command Prompt in that folder.
4. Run: python run_all_tasks.py
   On some systems use: python3 run_all_tasks.py
5. To run only the calculator's own tests and sample output: python milkrate.py
